# Python Calculator

A simple command-line calculator written in Python.

## Features
- Add, subtract, multiply and divide
- Handles invalid input and division by zero
- Type `q` to quit

## How to run
1. Install Python 3
2. Open a terminal in this folder
3. Run: `python calculator.py`

## Example
Operator: +
First number: 5
Second number: 3
Result: 5.0 + 3.0 = 8.0
